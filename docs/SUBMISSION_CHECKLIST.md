# Official PayPal AI Hackathon — submission readiness

Official source: https://paypalaihackathon.devpost.com/rules

Deadline: **November 12, 2026, 12:00 PM PST / 22:00 SAST**.

## Verified requirements

- [x] Real runnable application with source, original UI, README and favicon
- [x] PayPal Sandbox Orders API integration code (needs your own credentials and live test execution)
- [x] AI model integration code (needs your own model API key and live test execution)
- [x] Public open-source MIT `LICENSE` bundled; must publish on GitHub
- [x] Written project description bundled
- [x] Script for less-than-three-minute demo bundled
- [ ] **You:** Configure `.env`, including PayPal Sandbox credentials
- [ ] **You:** Configure AI key and confirm `/health` returns `ai_configured: true`
- [ ] **You:** Run a live PayPal Sandbox end-to-end capture and test on your machine
- [ ] **You:** Inspect and test all responsive UI routes and record the running application
- [ ] **You:** Publish original public GitHub repository and upload code
- [ ] **You:** Record and publish a YouTube demo **under three minutes**
- [ ] **You:** Submit GitHub, demo link / setup steps, text, tools used and video link on Devpost before deadline
- [ ] **You:** Keep a working judge-accessible copy available through the judging period ending December 15, 2026

## Judging criteria, equally weighted (20% each)

1. **Technical implementation** — demonstrate a genuine PayPal Sandbox order+capture, real optional LLM output and deterministic coalition algorithm.
2. **Design** — coherent minimal landing/auth/workspaces/search/profile/request/project/Guardian and legal pages.
3. **Potential impact** — local service discovery and equitable opportunity for small businesses, including remote cross-border services.
4. **Innovation** — cooperative Opportunity Assembly rather than another product-only storefront; 5IR-inspired consent and transparency.
5. **Presentation** — show a single buyer request, AI-assisted coalition suggestion, quote, approval and verified capture end-to-end.

Potential award categories: Best Overall, Most Impactful, Most Creative, Best Use of PayPal + AI, Best Use of Agentic Commerce. Do not claim sponsor-specific tool prizes without including that sponsor's tool.

**Do not represent** seed sample profiles as real businesses, deterministic explanations as LLM inference, proposal allocation as a binding agreement, or a PayPal CREATED order as a completed payment.
